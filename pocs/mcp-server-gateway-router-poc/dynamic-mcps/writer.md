# writer

Rewrites text in plain English. Every tool here is carried out by claude -p.

## summarize
Summarizes a text in one sentence.
- text (string, required): the text to summarize

Read the text and write one short plain sentence that keeps its main point. Answer with that sentence only.

## translate
Translates a text into another language.
- text (string, required): the text to translate
- language (string, required): the target language, for instance Portuguese

Translate the text into the language. Keep names and numbers as they are. Answer with the translation only.
